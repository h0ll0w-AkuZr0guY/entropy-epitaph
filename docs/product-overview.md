# 产品介绍 / Product Overview

## 熵逝碑林 / Entropy Epitaph

> **万物终将风化，连遗忘本身也会被遗忘。**<br>
> **Everything decays. Even the memory of forgetting.**

一座所有事物都会风化的数字墓园。用户可以为任何“死去”的东西立碑，但碑文、碑体，甚至“曾经存在过”的证明，都会持续磨损、崩塌并最终消散。

## 核心闭环 / Core Loop

1. **立碑 Erect**：创建代码碑、遗物碑、链接碑或无名碑。
2. **风化 Decay**：熵值按真实时间增长，并加入 `[-0.1, +0.2]` 的扰动。
3. **擦拭 Delay**：每天一次，回退量为 `0.05 × (1 - entropy)²`，越晚越无力。
4. **寂灭 Vanish**：碑体倒塌并生成 `EXTINCT-xxxx-xxxx-xxxx` 凭证。
5. **遗忘 Forget**：凭证继续熵增，最终从消逝档案中丢失。

## 四类墓碑

| 类型 | 纪念对象 | 衰变叙事 |
|---|---|---|
| 代码碑 / Code | 废弃项目、分支、需求 | 变量与结构错位，注释消失，最后只剩字符碎片 |
| 遗物碑 / Relic | 关系、梦想、回忆、未说的话 | 细节模糊、段落错乱，只留下情绪残影 |
| 链接碑 / Link | 404 网站、死博客、失效页面 | 捕获最后快照和摘要，再看它逐渐破碎 |
| 无名碑 / Nameless | 不愿说明的事物 | 没有正文，仅以沉默完成整个风化过程 |

## 五个阶段

崭新期 `0–0.20` → 风化期 `0.20–0.45` → 锈蚀期 `0.45–0.70` → 废墟期 `0.70–0.90` → 寂灭期 `0.90–1.0`。

内容衰变与载体衰变同步发生。三种风格在创建时锁定：CSS/SVG 模糊、Canvas 像素噪声、ASCII 字符崩坏。

## 墓园体系

- **个人墓园**：查看、筛选、擦拭自己的碑。
- **无名墓区**：匿名公开碑；陌生人可凭吊一次，不得到反馈。
- **消逝档案**：只留下凭证编号和时间，条目本身也逐渐变淡。
